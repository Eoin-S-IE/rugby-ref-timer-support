# Rugby Ref Timer Support

Rugby Ref Timer is an Apple Watch app for rugby referees.

It helps track elapsed time, playing time, time-off periods, halves, and yellow-card countdowns during rugby matches.

## Common Questions

### Does Rugby Ref Timer keep score?

No. Rugby Ref Timer is focused on match timing and card timing only.

### Does Rugby Ref Timer require an account?

No. Rugby Ref Timer does not require an account or login.

### Does Rugby Ref Timer collect personal data?

No. Rugby Ref Timer does not require an account and does not collect, store, or share personal data.

## Privacy

Rugby Ref Timer does not collect, store, or share personal data.
